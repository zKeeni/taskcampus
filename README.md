# TaskCampus

Aplicación web para la gestión de tareas estudiantiles desarrollada con Angular, FastAPI y PostgreSQL.

## Estructura del Proyecto
- `specs/`: Especificaciones funcionales del sistema.
- `frontend/`: Aplicación cliente desarrollada en Angular con Tailwind CSS.
- `backend/`: API REST desarrollada en Python con FastAPI.

## Requisitos Previos
- Node.js y Angular CLI
- Python 3.9+
- PostgreSQL
